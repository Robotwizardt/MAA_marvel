# MuMu 12 ADB 验收清单

本清单用于国服《漫威终极逆转》、MuMu 模拟器 12、竖屏 `720×1280`。正式发布前应保存 Maa 日志和失败画面；测试账号不要存放需要保护的高价值征服门票。

## 前置条件

1. MuMu 12 已开启 ADB/调试，国服游戏已登录并停在主页。
2. 通用 UI 只连接一个 ADB 设备，设备截图确认为 `720×1280`。
3. 安装包根目录已经执行 `python -m pip install -r agent/requirements.txt`。
4. 首次测试使用默认配置：OCR 智能选牌、试炼之地、不自动撤退、不 SNAP。

## 分阶段验收

### 1. 安全导航（不匹配）

- 从主页进入模式选择与征服页面。
- 能识别已有征服进度和干净的赛前页面。
- 无限档出现付费/金块提示时必须拒绝进入。
- 到达“开战”按钮后手动停止，不点击开战。

### 2. OCR 智能选牌

- 明确授权实际匹配后，完成至少一场试炼之地对局。
- 应优先打出当前能量可支付的最高费用牌；出牌后重新识别剩余手牌并继续出牌。
- 手牌只向三个安全区域拖动，零能量或没有可支付牌后停止拖牌。
- 结算后返回征服流程，日志中的对局计数增加一次。

### 3. 阿加莎托管

- 使用包含阿加莎的牌组，策略改为“阿加莎托管”。
- 脚本不主动拖牌，只处理结束回合、结果和下一局导航。

### 4. 撤退、认输与 SNAP

- 分别验证指定回合后撤退，以及撤退后“继续下一轮/认输整场”。
- SNAP 先用“每局必定执行”验证一次，再用固定概率观察日志决定。
- 每一种会改变对局结果的操作都应单独获得测试授权。

### 5. 恢复与停止

- 匹配超时后进入恢复；关闭自动重启时必须停止并记录原因。
- 开启自动重启时验证关闭并重新启动游戏后可返回主页。
- 最大对局数、最大运行分钟数到达后不再发起新匹配。
- 连续运行 60 分钟，确认没有误触支付、死循环或持续随机点击。

## 通过标准

- 没有购买门票或消耗金块。
- 识别不确定时停止、回退或恢复，不盲点。
- 随机与阿加莎主策略各完成至少一场；OCR 只记录诊断结果，不作为发布阻塞项。
- 所有停止和恢复原因能从日志定位，失败截图与对应时间点一致。
