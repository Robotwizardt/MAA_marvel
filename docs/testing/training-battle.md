# 训练模式战斗逻辑测试

这个测试任务只负责当前一个我方回合，不负责进入训练模式，也不会进入征服或消耗门票。

## 使用方法

1. 手动进入训练模式并开始一局对战。
2. 等到右下角出现“结束回合”，保持在我方可操作状态。
3. 在任务列表中只勾选 `训练模式-OCR选牌测试（单回合）`。
4. 点击执行，观察本回合的拖牌与结束回合动作。
5. 下一回合可再次执行同一任务。

如果不在我方回合，入口识别会失败并停止，不会盲目拖动。

## OCR 选牌业务流

1. OCR 识别底部当前能量。
2. OCR 用重叠窗口扫描手牌顶部的费用数字，去重后按横向位置还原当前手牌，适配手牌较多时的重叠布局。
3. 过滤低置信度和费用高于当前能量的牌。
4. 从可支付手牌中选择费用最高的一张；同费用时选择最左侧。
5. 依次尝试玩家侧三个场地，并通过“能量下降或手牌减少”确认出牌成功。
6. 成功后重新识别能量、费用和动态手牌位置，再次选择当前最高费用牌。
7. 重复直到零能量、没有可支付手牌、最高费用牌在三个场地均无法放置或达到安全上限。
8. 点击“结束回合”。

## 判定重点

- 不应再打开中间地点详情弹窗。
- 第一张牌打出后，后续拖牌起点应随手牌重新排布。
- 满场地时应尝试其他场地，每个场地最多尝试一次。
- OCR 策略应优先打出当前能量可支付的最高费用牌。
- 无牌可出时应正常结束回合，不应停在死循环中。
