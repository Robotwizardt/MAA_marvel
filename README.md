# MAA_marvel

面向国服《漫威终极逆转》的 MaaFramework 自动化项目，支持征服模式与天梯模式自动匹配、出牌、结算和异常恢复。

## 当前支持范围

- 国服安卓客户端，画面基准为横屏 `1920×1080`。
- 优先支持 MuMu 模拟器 12；其他模拟器需要提供标准 ADB 连接并保持相同分辨率。
- 征服模式：试炼之地、白银、黄金、无限四档入口识别。
- 天梯模式：自动关闭训练模式、从主页开始匹配、结算后返回主页继续下一局。
- OCR 智能选牌与阿加莎托管：OCR 会识别当前能量和全部手牌，反复打出可支付的最高费用牌。
- 支持 SNAP、指定回合后撤退、按运行小时领取任务奖励、匹配超时和异常重启。

暂不支持限时活动。

## 安装与启动

1. 下载并解压对应平台的发布包，不要改变包内 `agent_runtime`、`resource` 和 `interface.json` 的相对位置。
2. 运行包内通用界面；发布包已经包含独立 Agent，不需要另外安装 Python。
3. 在控制器中选择 `ADB`，连接 MuMu 12 的游戏实例，确认显示分辨率为 `1920×1080`。
4. 保持国服游戏已登录，选择“征服模式自动对战”，检查配置后开始。

MuMu 12 找不到设备时，请先在模拟器设置中开启 ADB/调试功能，再重新扫描设备。不要同时选择多个模拟器实例。

## 配置默认值

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 出牌策略 | OCR 智能选牌 | 另有阿加莎托管 |
| 最高征服档位 | 试炼之地 | 选择更高档后会按策略向下寻找可用入口 |
| 保留门票数 | 白银/黄金/无限各 1 张 | 仅在现有数量严格大于保留数时进入，否则逐级回退到试炼之地 |
| 每日通行证经验上限后结束 | 关闭 | 可手动开启；关闭时会关闭上限提示并继续对战 |
| 自动撤退 | 关闭 | 可设为完成第 1–6 回合后撤退 |
| 撤退后 | 继续下一轮 | 也可认输整场 |
| SNAP | 关闭 | 固定概率模式默认概率为 46% |
| 领取任务奖励小时 | 0 | 0 表示关闭；大于 0 时每隔指定小时在当前整场结束后回主页领取每日任务奖励 |
| 匹配超时 | 600 秒 | 超时进入恢复流程 |
| 异常时自动重启 | 开启 | 关闭后遇到持续未知页面会等待重试，不会把异常误报为任务完成 |

## 付费与安全保护

项目不会自动购买征服门票，也不会点击任何金块支付入口。进入档位前会同时检查档位、门票与付费提示；状态不明确时选择停止或回退，不猜测点击。

建议首次使用时保持默认的试炼之地与 OCR 智能选牌，并观察完整一局。

任务停止、恢复、无票、识别失败和超时的原因会写入 MaaFramework 日志。自动恢复不会自行结束任务；排查问题时请保留 `debug` 目录中的日志和对应时间点截图。
